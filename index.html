    Logic Explanation

    I store the loot in an array so I can keep adding items while the page is open. Each item is an object that keeps its name and value together. One loop goes through the array and creates a list item for each treasure and the other loop adds the values in cents to calculate the total shown in both sections.

    Before adding loot, I use if statements to check the name and value. I check the party size when someone clicks Split Loot so they can start collecting items before they know how many people are playing. If the party size is valid and the list has loot, I divide the total by the number of members.
